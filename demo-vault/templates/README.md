# Vault templates

This opaque directory contains fixed `.md.tmpl` authoring formats. Replace every `{{placeholder}}`, preserve required metadata and human-owned markers, then publish the result in its canonical collection. For `{{actor}}`, use `<producer>/<version>` for an agent, `human:<id>` for a person, or `process:<id>` only for an automated process. Templates are never indexed or graphed as knowledge.

# Human Learning

Human Learning is a local-first Markdown and PDF learning environment for
VS Code and Cursor. It combines:

- an Obsidian-style live Markdown editor;
- a PDF reader with portable text-fragment links and anchored discussions;
- backlinks, outlines, daily notes, and a filesystem-backed knowledge graph;
- explicit **Add to Chat** handoff for supported agent extensions; and
- an experimental, sanitized web reader for attaching selected passages.

The extension keeps durable learning artifacts in ordinary files inside the
workspace. Agent handoff attaches context to a draft and does not submit a
message automatically.

Source, documentation, development instructions, and issue tracking are in the
[Human Learning repository](https://github.com/t04dJ14n9/human-learning).

Human Learning Markdown is a VS Code markdown editor for local-first linked notes. It provides a custom markdown editor with Vim-mode support, wiki links, backlinks, forward links, and document outline views.

## Features

- Opens `*.md` files with the Human Learning Markdown custom editor by default.
- Supports wiki links and Markdown links across a workspace.
- Shows backlinks, forward links, and outline views in the Human Learning activity bar.
- Runs as a standalone markdown editor in ordinary VS Code workspaces, without requiring a Human Learning vault.

## Commands

- `Human Learning: Open In Markdown Editor`
- `Human Learning: Refresh Links`
- `Human Learning: Show Backlinks for Current File`
- `Human Learning: Toggle Vim Mode`

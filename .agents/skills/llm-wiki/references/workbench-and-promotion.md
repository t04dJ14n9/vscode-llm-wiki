# Workbench and promotion

`inbox/` is unprocessed material, `tasks/` is thorough operational state,
`tasks/current.md` points to zero or one focus, and `scratch/` holds immature
hypotheses. None is durable evidence.

Promote verified understanding into compiled pages. `output/` holds polished
reports/designs; binary renders go in assets with role `derived`. `examples/`
holds stable illustrative code with runnable instructions and tests. Exploratory
demo code belongs in scratch or the current task.

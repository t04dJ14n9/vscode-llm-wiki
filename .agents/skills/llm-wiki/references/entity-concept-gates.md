# Entity and Concept gates

Enrich an existing page automatically. Create an Entity only when no duplicate
exists, it is a durable named thing central to authoritative evidence,
independently searchable, clearly scoped, and supports useful identity,
ownership, and relationship prose. Do not create Entities for functions,
files, RPCs, passing mentions, or temporary objects.

Create a Concept only when no duplicate exists and the subject is a reusable
mechanism, invariant, pattern, workflow, failure mode, or process with
evidence-backed value beyond the conversation. Ask when identity or scope is
ambiguous and before fan-out touching ten or more pages.

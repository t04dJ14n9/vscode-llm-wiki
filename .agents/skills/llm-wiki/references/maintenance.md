# Maintenance

Run the local index builder, check mode, layered validator, Git LFS inspection,
and diff checks. Confirm `_index.md`/`_log.md` are regular canonical files,
raw/asset hashes remain intact, registered code bindings are safe, and opaque trees were not entered.
Add a newest-first log entry for material changes.

Validation layers are `okf-base`, `karpathy-vault-v1`, and `project-policy`;
never describe a local profile failure as base OKF nonconformance.

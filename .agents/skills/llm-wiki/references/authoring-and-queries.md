# Authoring and queries

Search before creating. Enrich the smallest durable page that already answers
the same question. Start with a direct definition or answer, separate sourced
facts from synthesis, attach each load-bearing claim to a `sources[].id`
footnote, and state uncertainty.

Use Summary for narrative orientation, Entity for a durable named thing,
Concept for a reusable mechanism, Comparison for a decision frame, Query for
an expensive durable answer, and Playbook for executable guidance. Conflicting
evidence keeps affected knowledge draft and presents both positions.
